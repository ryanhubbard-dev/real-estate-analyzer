# real-estate-analyzer
Python application for analyzing housing markets and identifying potentially undervalued properties
## Project Overview

This project analyzes residential real estate data to identify
potentially undervalued properties.

The initial focus is Cape Royale, Texas, with the goal of
expanding to additional housing markets.

## Planned Features

- Import and clean property listing data
- Calculate price per square foot
- Compare properties against local market averages
- Identify potentially undervalued listings
- Visualize market trends using Python
